A terminal you can write into.

A normal PTY-backed terminal, plus a multi-line command composer and a tagged snippet library that lives where your hand already is. The terminal is the runner. The composer is where commands are actually authored.

Features

The shell you have, the editor you wanted.

$SHELL

A real PTY

Spawns your login shell via portable-pty. xterm.js renders. Resize, copy, paste, scrollback — same as any terminal.

Composer

Write commands like prose

A CodeMirror editor below the terminal with shell syntax highlighting. Paste — or Paste & run — when you're ready.

Snippets

A library of commands you wrote

Save the composer body, tag it, search it. Type into the composer and the snippet list filters live.

History · Tab

Ghost-text completion

The longest matching command you've run before appears faded after the cursor. Tab to accept.

shellcheck

Inline command validation

Composer body runs through shellcheck on every edit. Findings get translucent pink underlines with hover tooltips.

which

Command-token highlight

The first token of each line lights up bold accent-pink if it resolves via PATH or is a shell builtin.

Install

Build from source.

Binary releases will land once the snippet UX settles. Until then, the source builds cleanly on any recent Linux with pnpm, rustup, and Tauri's Linux build deps installed.

For best results, apt install shellcheck — the composer linter degrades silently if it's missing, but the inline command validation is half the point.

From source

# clone
git clone https://github.com/krill-software/terminal
cd terminal

# install + run
pnpm install
pnpm tauri dev

# or build release bundles (AppImage + .deb)
pnpm tauri build
